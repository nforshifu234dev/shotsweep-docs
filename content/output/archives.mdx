# ZIP archives

Add `--zip` to either `capture` or `diff` to bundle the output directory into a single `.zip`
file when the run finishes — one file to hand off to design, QA, or a client.

```bash filename="terminal"
shotsweep capture --url https://example.com --zip
```

```bash filename="terminal"
shotsweep diff old/manifest.json new/manifest.json --out ./diff --zip
```

The archive is written alongside the output directory, named after it — `./screenshots` becomes
`./screenshots.zip`. The output directory itself isn't added as a parent folder inside the
archive; its contents sit at the archive's root.

With `--out .` (the current directory) the archive is written to the **parent** folder, named
after the current folder, so it is never created inside the folder it is archiving. An archive that
can't be written completely is reported as an error instead of silently producing a partial file.

Both `capture` and `diff` print the resulting zip path when the run completes:

```text
Zip: screenshots.zip
```
