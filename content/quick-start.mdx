# Quick Start

## Capture a single page

```bash filename="terminal"
shotsweep capture --url https://tour-guide.nforshifu234dev.com --mode full
```

```text
✔ Resolved 1 URL
✔ Captured 1 screenshot → ./screenshots
Done in 2.4s
Manifest: screenshots/manifest.json
```

This writes screenshots into `./screenshots`, organized by hostname and page, plus a
`manifest.json` describing every shot:

```text
screenshots/
├── tour-guide.nforshifu234dev.com/
│   └── home/
│       └── full-1440x900.png
└── manifest.json
```

## Capture every page in a sitemap

```bash filename="terminal"
shotsweep capture --sitemap https://tour-guide.nforshifu234dev.com/sitemap.xml --out ./screenshots
```

## Capture a local dev build, two viewports, zipped

```bash filename="terminal"
shotsweep capture \
  --base http://localhost:3000 \
  --paths paths.json \
  --viewport 1440x900 \
  --viewport 390x844 \
  --zip
```

## Preview before capturing

`--dry-run` resolves your targets and prints them, without opening a browser:

```bash filename="terminal"
shotsweep capture --sitemap https://tour-guide.nforshifu234dev.com/sitemap.xml --dry-run
```
